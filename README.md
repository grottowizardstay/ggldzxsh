# Muraveynik gym and House of Culture in Minecraft

`build.py` holds the gym model and `dk.py` adds the House of Culture next to it; running `dk.py <dir>` writes the /fill and /summon commands and previews for both. `make_world.py <server.jar> <dir> [world name]` replays them on a Minecraft Java 1.20.1 server, checks the saved world against the model and zips it.
